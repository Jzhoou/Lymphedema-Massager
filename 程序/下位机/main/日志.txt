功能函数	To_arm() - 正转伸出 / back() - 反转收回

项目	说明
驱动芯片	PCA9685 (I2C地址 0x40)
PWM频率	50Hz
控制通道	6路舵机 (通道 0~5)
功能函数	setAllServos() - 批量设置 / setPulse() - 单路设置
PID控制	框架已搭建，比例控制(P)已实现，积分(I)和微分(D)预留接口

项目	说明
采集芯片	MY2901 (8通道)
通信接口	Serial4, 115200 bps
数据格式	20字节帧，支持BCD/HEX双格式
校准方式	7点分段线性插值
输出范围	0 ~ 2000g
4. 生物电阻抗测量模块 (AD5933.cpp/h)
项目	说明
测量芯片	AD5933
通信接口	I2C1 (SDA1/D18, SCL1/D19)
测量频率	20kHz / 50kHz 双频
校准方式	多次采样平均 (默认10次)
数据处理	冒泡排序去极值滤波
输出参数	阻抗值(Ω) + 相位角(°) + 阻抗比(Z20k/Z50k)
5. OLED显示模块 (DisplayHelper.cpp/h)
项目	说明
显示屏	SSD1306 (128x64)
通信接口	I2C1 (与AD5933共用总线)
显示内容	校准进度 / 测量结果 (双频阻抗值 + 阻抗比)
6. 通信协议模块 (BM53_Protocol.cpp/h)
项目	说明
通信接口	Serial2, 460800 bps
帧格式	帧头 0xAA 0x55 + 长度 + 命令 + 数据 + CRC16 + 帧尾 0x0D
支持命令	心跳、握手、设备信息、治疗控制、参数设置、数据上报等
传输策略	TCP类(可靠) / UDP类(实时) 区分处理

一、版本更新说明

本次版本基于 v1.0.1 完善版，优化 AD5933 生物电阻抗测量模块的校准方式，
将 AD5933_cal_measure 调试模块中的宏定义校准功能融合到主系统中，
实现校准方式的灵活切换，简化生产部署流程。

二、具体修改内容

1. AD5933.h 修改
   新增宏定义校准相关配置：
   - 新增校准系数宏定义（CAL_GAIN_20KHZ、CAL_PHASE_20KHZ、CAL_GAIN_50KHZ、CAL_PHASE_50KHZ）
   - 新增校准方式选择宏（USE_CAL_MACROS）
   - 新增频率定义宏（FREQ_20KHZ、FREQ_50KHZ）

2. main.ino 修改
   优化系统初始化流程中的 AD5933 校准部分：
   - 根据 USE_CAL_MACROS 宏选择校准方式
   - 宏定义为 1：直接使用预定义校准系数，跳过运行时校准，加快启动速度
   - 宏定义为 0：执行原有运行时校准流程，需要连接 470Ω 参考电阻

三、校准方式说明

1. 宏定义校准（USE_CAL_MACROS = 1）
   适用场景：生产环境、批量部署
   优点：上电即可使用，无需人工干预，启动速度快
   要求：校准系数已通过 AD5933_cal_measure 调试模块获取并正确填写

2. 运行时校准（USE_CAL_MACROS = 0）
   适用场景：调试阶段、更换 AD5933 模块后
   优点：可根据实际硬件情况动态调整校准系数
   要求：启动时需连接 470Ω 参考电阻到 AD5933 测量端口

在系统初始化结束后自动执行电机回零操作，确保设备每次启动都能回到正确的零点位置，
提高系统的一致性和可靠性。

二、具体修改内容

1. motor_control.h 修改
   新增回零相关配置：
   - 新增限位开关引脚定义（LIMIT_SWITCH_2_PIN、LIMIT_SWITCH_4_PIN）
   - 新增回零速度参数（HOMING_SPEED）

   新增电机回零功能实现：

   - 新增 motor_homing() 函数，实现电机回零逻辑

   - 在停止电机后添加10毫秒延迟，确保电机完全停止

   优化系统初始化流程：

   - 确保系统启动时自动执行回零操作
   - 在回零完成后添加10毫秒延迟，确保电机完全停止

三、回零功能说明

1. 回零逻辑
   - 检测限位开关状态：若已在零点（限位开关被遮挡，低电平），直接清零位置
   - 若不在零点，电机以低速（5 RPM）反转向零点运动
   - 触发限位开关后立即停止并清零位置
   - 支持两个电机独立回零，各自检测各自的限位开关

2. 安全保护
   - 回零超时保护：30秒超时后强制停止电机
   - 限位开关状态实时监测，确保回零过程安全可靠
   - 回零完成后自动停止电机并清零位置

3. 硬件要求
   - 限位开关：NPN输出型（无遮挡高电平，遮挡低电平）
   - 连接方式：2号电机限位开关连接D8引脚，4号电机限位开关连接D9引脚

3. 电机控制模块（motor_control.h/cpp）修改
新增 3 种步进控制函数 + 位置读取函数：

函数名	功能	控制方式
motor_step()	单电机步进	立即启动，不等待同步信号
motor_step_sync() ★	双电机同步步进	先分别设置参数，再发送广播指令同时启动
motor_step_async()	双电机异步步进	各自立即启动，适用于不同参数场景
motor_read_position()	读取电机位置	同步阻塞方式，500ms 超时
motor_read_all_positions()	批量读取所有电机位置	逐个读取，间隔 50ms 避免总线冲突
motor_process_response()	处理电机返回数据	非阻塞方式，需在 loop() 中持续调用
get_last_motor_position()	获取最近读取的位置	配合 motor_process_response() 使用
has_new_position_data()	是否有新位置数据	读取后自动清除标志
同步步进与异步步进对比：

对比项	motor_step_sync()	motor_step_async()
启动方式	广播指令同时启动	各自立即启动
指令标志位	byte[11] = 0x01（等待同步）	byte[11] = 0x00（立即执行）
同步精度	高，严格同步	低，存在先后时序
适用场景	需要双电机严格同步运动	两个电机运动参数不同时
位置读取协议说明：

发送指令：[ID] [0x36] [校验0x6B]（3字节）

返回数据：[ID] [0x36] [位置高字节] [位置中高字节] [位置中低字节] [位置低字节] [校验0x6B]（7字节）

电机步进上位机指令数据格式：

text
帧格式: [0xAA] [0x55] [长度] [0x34] [方向0x01] [数据7字节] [CRC16] [0x0D]

数据负载（7字节）:
  byte[0]     方向: 0x00=伸出(CW), 0x01=收回(CCW)
  byte[1-4]   步数: 4字节无符号长整型（高字节在前）
  byte[5-6]   速度: 2字节无符号整型（高字节在前，单位RPM）
4. 治疗状态机模块（TherapyStateMachine.h/cpp）新增
状态定义与流转图：

text
                   		     ┌──────────┐
          ┌─────────│  PAUSED          │─────────┐
          │ resume 	     └──────────┘           pause                  │
          v                              	                                                              │
    ┌──────────┐          start                   ┌──────────┐           │
    │   IDLE                 │─────────→│ RUNNING          │───┘
    └──────────┘←─────────└──────────┘
          ↑                                 stop                      │
          │                                                               │ time up
          │ exit_eme                                              v
    ┌──────────┐                       ┌──────────┐
    │ EME_STOP │                             │COMPLETED     │
    └──────────┘                      └──────────┘
核心功能：

五种状态：IDLE（空闲）、RUNNING（运行中）、PAUSED（暂停）、EMERGENCY_STOP（急停）、COMPLETED（完成）

状态转换保护：非法状态转换自动拒绝（如急停状态下禁止开始治疗，非运行状态不能暂停）

暂停/恢复机制：支持暂停计时，恢复后自动补偿暂停时长，重新计算结束时间

连接超时保护：断开连接 10 秒后自动停止治疗，通过 updateConnectionStatus() 统一管理

状态变化回调：通过 onStateChange() 注册回调函数，便于各模块响应状态变化

进度计算：根据已用时间和总时长自动计算治疗进度百分比（0-100%）

时间查询接口：getElapsedSeconds() / getRemainingSeconds() / getTotalSeconds()

5. 数据上报模块（DataReporter.h/cpp）新增
上报策略总览：

数据类型	上报间隔	触发条件	传输方式
压力数据	200ms（5Hz）	间隔到达 或 数据变化超过阈值	UDP（实时）
水肿数据	1000ms（1Hz）	间隔到达	UDP（实时）
电机状态	100ms（10Hz）	状态变化触发	UDP（实时）
治疗进度	1000ms（1Hz）	间隔到达	TCP（可靠）
优化特性：

压力数据变化检测：仅在数值变化超过阈值（2g）或归零时上报，减少无效传输

归零检测：传感器松开时主动上报一次零值，确保上位机状态同步

强制上报机制：治疗开始时调用 forceReportAll() 强制上报所有初始状态

上报统计：记录总上报次数 getTotalReports()，便于性能监控
